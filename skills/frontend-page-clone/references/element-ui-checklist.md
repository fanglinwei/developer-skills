# Element UI 组件完整性检查表

仅在当前项目使用 Element UI 时读取，按目标模块已确认的功能选择相关行；未涉及的类型直接略过，不为凑齐检查表扩展功能。

类型参考 [Element UI 官方组件目录](https://github.com/ElemeFE/element/blob/dev/examples/nav.config.json)，验收项为本技能的复刻要求。组件版本、复用优先级和样式规则遵循 [主技能](../SKILL.md)。

本表中的尺寸、颜色、图标、位置及弹层等外观检查均服从已选档位：档位 1 保留项目组件内部外观，按参考调整外层布局；档位 2 复用组件并按参考 1:1 调整样式。两档均核对完整文案、状态、交互与 mock 结果；档位 1 的预期风格差异不作为待修复缺陷。组件/样式、文案、mock/联动/测试分别按主技能的 ponytail 强度表执行。

| 类型 | 对应组件或能力 | 必须核对的完整性 |
| --- | --- | --- |
| 页面布局/栅格 | 项目页面封装、Layout（Row/Col）、Container | 页头、侧栏、主区、页脚、栅格比例、间距、对齐、断点和滚动区域；优先复用项目页面骨架。 |
| 按钮/按钮组 | Button、ButtonGroup | 文字、图标、类型、尺寸、分组、禁用和提交中状态；点击产生实际 mock 结果，防止重复提交。 |
| 图标/文字链接 | Icon、Link | 图标来源、尺寸、基线、间距、链接目标与禁用状态；图标操作有可访问名称，链接使用项目已有导航方式。 |
| 表单/表单项 | Form、FormItem | 字段绑定、标签、必填、默认值、校验时机、错误位置、提交和重置；失败保留输入，重开时按约定保留或清空。 |
| 文本/多行/搜索输入 | Input、Autocomplete | 占位、前后缀、清空、只读、密码、字数限制及文本域尺寸；搜索与 mock 结果联动，建议项选择和无结果状态正确。 |
| 数字输入 | InputNumber | 最小/最大值、步长、精度、控制按钮、空值及边界；输入与增减操作一致，不以字符串误算。 |
| 单选/多选 | Radio、RadioGroup、RadioButton、Checkbox、CheckboxGroup、CheckboxButton | 值与标签映射、选项顺序、禁用、按钮样式；全选/半选、数量限制及选择结果与数据一致。 |
| 下拉选择 | Select、Option、OptionGroup | 单/多选、分组、筛选、清空、已选标签、禁用项、空结果及加载；远程式搜索使用本地 mock，正确回显选中值。 |
| 级联选择 | Cascader、CascaderPanel | 层级字段、展开方式、路径回显、单/多选、父子关联、筛选和清空；懒加载使用 mock，正确区分节点与完整路径值。 |
| 开关 | Switch | 开关值、文字、颜色、禁用及变更结果；状态与 mock 数据同步，模拟失败时正确恢复。 |
| 滑块/评分/颜色 | Slider、Rate、ColorPicker | 范围、步长、刻度、区间值、评分精度、颜色格式及透明度；预览、确认、清空和只读状态按参考核对。 |
| 时间/日期选择 | TimeSelect、TimePicker、DatePicker（含日期时间模式） | 显示与绑定格式、单值/范围、粒度、快捷项、禁用范围、清空；起止顺序、日期边界和回显正确。 |
| 上传 | Upload | 入口、拖拽、文件列表、数量/类型/大小限制、预览和删除；用本地模拟上传覆盖进度、成功、失败和重试，不请求真实上传接口。 |
| 穿梭框 | Transfer | 两侧标题、数据、唯一键、选中项、筛选、禁用和移动操作；结果列表与绑定值同步。 |
| 列表/表格 | 项目列表封装、Table、TableColumn | 列序、表头、格式、行操作、选择、排序、筛选、展开、固定列及汇总/合并（适用时）；操作作用于 mock 数据，保留加载和空状态。 |
| 树形结构 | Tree | 节点键、层级、展开、当前节点、复选/半选、父子关联、筛选及拖拽（适用时）；懒加载和节点操作使用 mock。 |
| 分页 | 项目分页封装、Pagination | 当前页、每页数量、总数、跳页、布局和切页事件；筛选或增删后同步总数与有效页码，显示对应 mock 切片。 |
| 标签/徽标 | Tag、Badge | 文案、类型、尺寸、数量上限、圆点和隐藏条件；关闭标签同步更新数据，数值零与空值显示符合参考。 |
| 进度/加载/骨架 | Progress、Loading、Skeleton、SkeletonItem | 进度值、形态、状态和文案；加载作用域、遮罩、骨架结构、内容切换及结束清理，避免一直加载或遮挡操作。 |
| 空状态/结果页 | Empty、Result | 图示、标题、说明、操作入口及布局；与无数据、失败、成功条件对应，重试或返回入口实际有效。 |
| 描述列表/统计 | Descriptions、DescriptionsItem、Statistic | 字段顺序、标签、跨列、边框、排列方向及数值格式、单位、精度；长文本、空值与 mock 数据正确展示。 |
| 菜单导航 | Menu、Submenu、MenuItem、MenuItemGroup | 层级、方向、图标、激活项、展开、折叠、禁用及导航结果；与当前路由或本地视图状态同步。 |
| 标签页 | Tabs、TabPane | 标签、激活项、位置、样式、禁用、增删（适用时）；切换展示对应内容，按约定保留表单与筛选状态。 |
| 面包屑/页头 | Breadcrumb、BreadcrumbItem、PageHeader | 层级、分隔符、标题、返回入口和目标；与模块位置一致，不留下无效链接。 |
| 下拉菜单 | Dropdown、DropdownMenu、DropdownItem | 触发方式、菜单位置、分组分隔、禁用和命令；每个菜单项执行对应本地操作，关闭与键盘行为正确。 |
| 步骤条 | Steps、Step | 步骤顺序、标题、描述、图标、方向与当前状态；前进、返回及失败状态与实际流程一致。 |
| 弹窗/抽屉 | Dialog、Drawer | 标题、正文、底部操作、尺寸、方向、滚动；打开、确认、取消、关闭、重开完整，核对遮罩、Esc、焦点返回、滚动锁恢复及数据保留/重置。 |
| alert/确认/输入对话框 | 项目 alert 封装、MessageBox、Popconfirm，按实际用途使用 Dialog | 对照主技能的提示复刻规则核对弹窗样式、标题、正文及按钮文案；检查输入校验（适用时）、确认/取消/关闭分支，仅确认成功后执行操作，取消不修改 mock 数据。 |
| 文字提示/气泡 | Tooltip、Popover | 内容、触发、位置、宽度、箭头和显示条件；检查焦点触发、关闭方式、边缘定位与弹层内部操作。 |
| toast/消息/通知/页内警告 | 项目 toast 封装、Message、Notification、Alert | 对照主技能的提示复刻规则核对完整文案及动态值；检查类型、图标、位置、时长、关闭及触发条件，区分页内 Alert 与浮层反馈，成功提示与操作结果一致，取消和失败不误报成功。 |
| 卡片/折叠面板/分割线 | Card、Collapse、CollapseItem、Divider | 标题、操作区、内容间距、边框、阴影及分割文案；展开项、手风琴状态与内容完整，不遗漏折叠后的区域。 |
| 图片/头像 | Image、Avatar | 来源、尺寸、形状、裁切、占位、失败回退；核对懒加载及图片预览的打开、切换、关闭和层级。 |
| 轮播 | Carousel、CarouselItem | 内容顺序、尺寸、指示器、箭头、切换与循环；自动播放按参考启用，检查暂停、恢复及离开页面后清理。 |
| 时间线/日历 | Timeline、TimelineItem、Calendar | 时间顺序、节点、日期网格、自定义内容、当前值和范围；日期选择或切换与 mock 内容联动。 |
| 回到顶部/无限滚动 | Backtop、InfiniteScroll | 目标滚动容器、触发位置、显隐和加载条件；追加 mock 数据不重复触发，正确显示无更多内容及失败重试。 |

参考中出现但表内未列出的组件，按其真实结构、状态、事件与联动补充核对。
