# 移动端适配

目标或参考涉及移动应用时读取；通用流程沿用主技能。

## 取证与测量

- 确认 iOS、Android 或跨平台框架及版本，定位视图层级、约束、主题、字体与共享控件，按任务加载匹配的框架/模拟器技能。
- 用已安装且获准的平台视图检查、模拟器或真机工具。只有截图时直接分析；模拟器在桌面运行不改变目标平台，确需桌面窗口取证时另读[桌面指引](desktop.md)。
- 记录设备、系统、方向、逻辑尺寸、截图尺寸、密度/缩放、主题与字体缩放，区分 point、dp/sp、框架单位与物理像素。区分内容、安全区、状态/导航栏、手势区和软键盘。

## 实现与验收

- 沿用平台组件、布局、主题、资源及架构，不用 Web 页面替代原生目标；WebView 网页内容另读[Web 指引](web.md)。保留列表单元/视图身份、绑定、手势与导航，不缩小平台要求的触摸区域或破坏辅助技术语义。
- 使用平台动画能力，处理页面离开、中断及资源释放，遵循主技能的减少动态效果与动态验证要求。
- 在匹配设备、方向、系统、主题、字体缩放和状态下对照；覆盖已支持尺寸、横竖屏、安全区、长文本、滚动、键盘布局，以及受影响的触摸、手势、返回/导航、输入焦点和辅助功能。
- 运行相关平台构建/测试；区分模拟器和真机覆盖，缺少真机或录制条件时明确限制。
