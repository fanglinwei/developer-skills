# Web 界面适配

目标或参考涉及网页内容时读取；通用范围、测量、实现及交付沿用主技能。

## 取证与组件

- 确认 Web 框架、样式方案、组件库及版本。复用业务封装，通过公开 props、插槽、主题与局部样式调整；Element UI 不混用 Element Plus API，不另造列表、按钮、抽屉、弹窗或消息服务。
- 用已安装且允许的浏览器工具读取 DOM、计算样式、实际加载字体和元素边界，追踪继承、选择器优先级、默认样式与弹层挂载位置。
- 核对 CSS 视口、浏览器缩放、设备像素比和裁剪原点，建立截图像素到 CSS 像素的映射。浏览器外壳或系统弹层需屏幕取证时另读[桌面指引](desktop.md)，网页调试仍用浏览器工具。

## 实现与验收

- 沿用路由、资源、样式方案与断点；容器外弹层使用专用类或项目支持的局部入口。必要结构调整保留 HTML 语义、事件、key、数据绑定和状态。
- 简单动画用局部 CSS transition/keyframes；CSS 无法表达已有状态变化时才补事件逻辑，遵循主技能的取消、清理及动态对照要求，支持 `prefers-reduced-motion`。
- 在匹配的视口与缩放下检查断点、滚动、溢出、弹层定位和适用状态；回归键盘/焦点，以及项目支持的移动和桌面浏览器布局。缺浏览器或录制能力时明确未验证范围。
