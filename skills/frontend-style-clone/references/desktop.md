# 桌面适配与屏幕取证

目标为桌面应用，或需桌面应用提供参考证据时读取；通用流程沿用主技能。

## agent-desktop 取证

- 查看运行中的桌面应用前读取当前可用的 `$agent-desktop`，沿用其初始化、CLI 文档、权限、任务专属会话/光标、错误处理与结束流程；不在本文件维护命令副本。
- 使用该技能的后台 headless 语义接口，指定应用，多窗口时指定窗口。先观察再定位，不抢系统鼠标/前台焦点，不为截图或光标激活窗口、点击业务控件；仅分析时保持只读。
- 按当前 CLI 能力获取目标窗口截图、元素、边界、文本与状态，记录应用、窗口、内容区、时间及显示条件，只保存必要证据。区分窗口外框、标题栏、内容区、屏幕原点、物理像素和逻辑坐标，核对显示缩放与裁剪映射。
- 可访问性树可能遗漏自绘控件，边界/角色/文本不证明字体、颜色、圆角、阴影或可见轮廓；用截图和源码交叉核实，不补造精确读数。
- CLI、权限、截图/光标或定位受限时报告实际阻塞，继续已有材料支持的分析，不改用物理输入、抢焦点或其他工具绕过约束。结束自己创建且不再使用的会话，共享会话按协调规则处理。
- 网页 DOM/样式调试用[Web 指引](web.md)；移动模拟器的实现与验收用[移动指引](mobile.md)，桌面窗口仅是取证来源。

## 实现与验收

- 确认操作系统、框架与版本，定位视图层级、约束、主题/资源、外观继承和浮层所属窗口，按任务加载框架、窗口或构建技能；SwiftUI/AppKit、Windows/Linux 框架各用自身能力，Electron 网页内容按 Web 处理。
- 通过原生/框架控件的公开局部配置实现，保留窗口生命周期、视图身份、绑定、菜单、快捷键、焦点与输入。区分应用内容和系统管理的标题栏/菜单/控件；显著系统限制按主技能澄清，不移除系统语义凑图。动画覆盖窗口关闭、取消和资源释放。
- 在匹配内容尺寸、缩放、系统、主题和状态下对照；检查已支持的窗口缩放、最小尺寸、滚动、弹层、多显示器，以及键盘、快捷键、焦点链、辅助功能和窗口生命周期。屏幕坐标不直接作为视图尺寸。
- 观察参考不触发业务操作；操作目标须遵守任务授权与 agent-desktop 的操作验证闭环。平台构建/测试与屏幕对照分别报告，缺环境时明确静态、已观察和未验证范围。
