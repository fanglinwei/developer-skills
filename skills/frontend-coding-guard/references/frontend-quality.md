# 按需补充前端质量约束

先检查项目规范、组件和现有检查是否覆盖本次改动；已有等价约束就复用。以下仅补缺口，不要求安装新工具或整改无关代码。

- 类型与列表：不以 any、断言或禁用规则掩盖可建模的问题；不直接修改 props 或共享状态；列表用稳定唯一 key，重排或插入删除时不用索引。
- 语义与名称：复用语义组件或原生控件；按钮有 type 和名称，控件有关联标签，图标按钮有可访问名称；图片 alt 合适，装饰图用空 alt，ARIA 不替代原生语义。
- 键盘与反馈：保留可见焦点；弹层处理初始焦点、关闭与焦点返回，模态约束焦点；动态错误可被辅助技术感知，状态不只靠颜色，文本保持可读。
- 布局与资源：沿用项目令牌、样式和目标视口，检查长文本及溢出，不擅自扩平台；尊重 prefers-reduced-motion，首屏关键图片不一律懒加载；性能优化须有证据。
- 验证承接：类型与 lint 只能证明其配置实际检查的规则，不能代替键盘、焦点、异步与数据恢复验证。文案或 CSS 涉及可访问名称、内容隐藏、焦点或命中区域时也验证相应行为；用现有设施或可复现步骤说明结果与缺口。
