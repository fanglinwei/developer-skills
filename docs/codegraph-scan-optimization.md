# CodeGraph 优化记录

本页记录 2026-10-30 的改动与验证；现行流程和命令以 [Skill 正文](../skills/codegraph-project-scan/SKILL.md)为准。

## 改动与 hooks 取舍

- 从“每轮只同步一次”调整为“首次代码读取前维护；源码未变复用，变更后重新维护”，覆盖同轮编辑、外部改动及工程/worktree 切换。
- 保留提取版本升级重建、维护后健康检查、每工程每轮最多一次重建与故障回退；持锁及路径错配优先处理。
- 无索引时按项目规则回退；只在明确授权启用时初始化，不自动安装 CLI、hooks 或修改配置。正常同步不逐次汇报，异常和覆盖缺口须披露。

主文件从 4,153 字符压缩到 2,369 字符（43.0%），UTF-8 从 8,825 字节降至 4,630 字节；未将正文迁入隐藏参考文件。本记录不是运行依赖。

当时未加入 Codex hooks：启动/轮次事件不能覆盖同轮后续编辑，编辑后或停止事件来不及保护当前读取；同步 `PreToolUse` 最接近查询前维护，但仍有工具覆盖、外部编辑和复合命令盲区。若漏同步反复出现，再考虑显式启用的查询前 hook。

未来实施前须重新核对[官方 Hooks 文档](https://learn.chatgpt.com/docs/hooks)与宿主支持，审阅并信任确切定义，检查重复配置；按根目录/worktree 隔离状态、维护互斥并复查、排除维护命令，限制等待且如实回退。不能仅按 turn_id 缓存，也不能宣称 hook 覆盖所有代码读取。这是设计评估，未部署或实测。
