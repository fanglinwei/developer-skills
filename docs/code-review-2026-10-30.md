# Code Review 2026-10-30 源码改进

## 最终交付

本次以 [Skill 正文](../skills/code-review/SKILL.md)及其两个按需参考为最终版本，不再以持续扩充评测工作作为交付前提。本次直接改进审查能力：

- 以行为变化串联真实入口、调用方与结果，追踪异步状态、接口数据、权限和持久化的受影响路径。
- 核实当前实例的参数、配置及防护；分别验证核心主张和辅助事实，减少错误对比导致的误报。
- 阅读现有测试的实际入口、替身和断言，区分已验证行为与尚未证明的判断。
- 沿同一触发路径推演修复后的成功、失败、并发和清理结果，覆盖必要调用方，避免只修症状。
- 审查范围完成后直接提交一份报告；无新变化或具体未决问题时停止重复取证与扩大检查。

验证：排除 Finder 元数据的临时源码副本通过现有包校验和全部 15 项测试。它们验证包结构与既有样例，不证明模型准确率提升。未新增或修改评测器、采集器、模型评测与测试代码。独立的 quick_validate.py 因当前 Python 缺少 PyYAML 未运行成功，未为此安装依赖。

最终 Skill 文件已同步到本机原有 developer-skills 插件的 code-review 目录，并逐文件核对内容；同步前保留本地备份。用户随后授权提交与发布，本次最终版本纳入 v0.1.6 标签及发布包。旧缓存的本地同步可能被重装覆盖，后续安装应使用 v0.1.6。

## 规则改动

最新依赖整理：daily/deep 与所有领域统一仅以 ponytail-review 为必需依赖；karpathy-guidelines 在关键需求歧义、修复方案范围/复杂度取舍或专项简化时按需辅助。Web 检查归入主审流程，不依赖额外前端开发 Skill。必需依赖或用户/项目明确要求的 Skill 缺失时局部阻断；仅作可选辅助的 Skill 不可用不自动停止主流程。新旧专项验证保存在仓库旁 code-review-eval/iteration-6，历史轮次分数不覆盖此调整。

- 前三轮正式对照保持原依赖组合，不凭小样本平局删除依赖。随后按用户明确要求，取消 Web 审查对 frontend-safe-development 的强制调用；所有审查仍加载 ponytail-review，Web 仍结合 karpathy-guidelines，Web 检查由主审流程承担。
- 严重度描述后果，合入阻断依当前必要验收与仓库策略；中或低的已确认缺陷也可阻断。没有确认错误但关键事实/验证缺失时，给“暂无法判断”。
- daily 报告尽早给结论，每项保留位置、触发与实际/预期、依据/归因、证据和最小修复，不重复通用清单；deep 按相关性保留需求映射。
- 增加[分类与报告示例](../skills/code-review/references/review-examples.md)，仅分类或输出边界不清时读取。
- 修复本次回归不等于满足全部验收；用户要求完整验收时，对已核实的既有缺口单列来源和剩余条件。

后续源码将需求对应融入发现或必要覆盖摘要，daily不再单独列完整覆盖表、排除过程和无问题维度；deep仍保留理解跨模块影响所需的映射。结论和相同风险各说明一次，具体发现的证据字段不减少。提交报告前复核目标状态与取证文件内容，变化只重核受影响路径。

本轮测试仓库的Git初始化、精确暂存和一次基线提交另有明确授权；源码仓库没有Git写权限。本任务没有写入安装缓存。自然触发使用测试时Codex宿主已安装的相同description，不把它解释为新版正文的执行验证；不修改触发描述来适配这些查询。

## 第四轮：紧凑输出与过程证据

针对第三轮报告长度基本不变，以及少数执行声明无原始事件支持的问题，主流程现在明确：只有实际读取并应用才称已使用 Skill；命令的执行、成功、失败或拒绝须有工具结果，不补写未发生的尝试；复合命令分开判断查询、差异与测试。daily 默认直接给范围与结论、发现、实际验证三段，保留全部证据字段，避免重复步骤和收尾。

对照基线为取消 Web 前端 Skill 强制调用后的第三轮最终源码。复用四个冻结任务，新增文件保存失败与 SQLite 唯一入队的反证包；输入、真值、自检、评分标准和运行结果在仓库旁code-review-eval/iteration-4。主文没有包含这两个新任务的答案。所有实验结果以该轮报告为准，不把措辞调整当作已证实效果；真实依赖卸载、服务恢复和预算拦截仍不在本轮覆盖内。

初轮候选仍出现无原始工具记录支持的失败尝试陈述。进一步强调“交付前逐句回查”的六任务补充未消除问题，因无改善依据而未采纳，保留初轮候选作为交付。补充版本、输出和评分另存refinement，不替换原12次随机对照，也不把自适应补充的长度统计当作预声明成功。规则要求不等于宿主强制校验，过程可靠性仍未闭环。
